# 🍽️ Zomato AI Premium Sales Analytics Dashboard

A premium, interactive Sales Analytics Dashboard inspired by Zomato, built using HTML, CSS, JavaScript, Chart.js, and PapaParse.

This project analyzes restaurant order data from a CSV dataset and converts it into an interactive business dashboard with KPIs, charts, filters, and reports. It demonstrates frontend development, data visualization, and dashboard design skills.

---

# 📌 Project Overview

This dashboard helps restaurant owners, managers, and business analysts understand sales performance through interactive charts and live business metrics.

Users can filter data, analyze customer behavior, identify top-performing restaurants, monitor monthly revenue, and generate business insights without writing any code.

# ▶️ How to Run

### Step 1

Download or Clone this repository.

### Step 2

Open the project in **Visual Studio Code**.

### Step 3

Install the **Live Server** extension.

### Step 4

Right-click **index.html**

Choose

**Open with Live Server**

### Step 5

The dashboard opens automatically in your browser.
